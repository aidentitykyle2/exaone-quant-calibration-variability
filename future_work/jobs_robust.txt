# 설계: 본 논문의 7.8B 시드 실험(18시드 x {ko, en_instruct}, n=256, GPTQ)과
#       완전히 같은 조건에서 집계 방식만 geomedian(K=4)으로 바꾼다.
#       총 캘리브레이션 표본 수는 256으로 동일하다 — 예산을 늘려서 나아진 것이

#       기준선 7.8B GPTQ: SD(X) = 2.00 %p, 18시드 중 5건 부호 반전.
#       SD(X)가 유의하게 줄고 부호 반전이 사라지면 완화 가설 채택,
#       줄지 않으면 '변동의 원인은 집계 방식이 아니다'라는 결과가 된다(둘 다 유용하다).

# 분석: final_analysis.py / single_run_risk.py 를 출력 이름
